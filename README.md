# ParToss — The Parma Tosser

FTN echo processor (tosser/scanner/packer) by Serge Koghin, a replacement for
Squish. Build 1.10.07x/SEC and SAF: Dmitry Protasov, Sergey Fadeyev and others.
Platforms: DOS (32-bit), OS/2, Windows, Linux, FreeBSD.

The text below is taken from the program's documentation (`doc/partoss.doc`,
in Russian, CP866). Release notes: `doc/whatsnew.doc`.

## Назначение и особенности программы

Программа Parma Tosser (далее — ParToss) предназначена для управления
эхо-конференциями в FTN-сетях. Основные функции, выполняемые программой —
импорт эхо-почты из пришедших почтовых архивов в локальную базу и экспорт
новых писем в почтовые архивы для отправки подписчикам. ParToss написан для
замены известного эхопроцессора Squish. Поддерживаемые форматы — `*.Msg` для
нетмейла и Squish-формат для эхомейла.

Программа содержит встроенные функции для сопровождения базы, внутренний
эхо-менеджер для управления подпиской, функцию автоматической генерации и
отправки писем по расписанию, функцию управления персональной почтой, а также
ряд вспомогательных функций. Основные методы работы и особенности поведения в
различных ситуациях настраиваются с помощью набора текстовых файлов
конфигурации.

## Установка и конфигурация

Установка и конфигурация состоит из трех шагов:

- разверните архив с программой и файлами конфигурации в какой-нибудь каталог
  на Вашем диске;
- отредактируйте файлы конфигурации `partoss.cfg`, `compress.cfg` и
  `route.cfg`, а также другие текстовые файлы (шаблоны и прочие), внимательно
  читая комментарии в этих файлах;
- исправьте `.BAT` или `.CMD`-файлы, управляющие работой Вашей станции, или
  другие файлы, выполняющие те же функции.

Готовые сборки: [Releases](https://github.com/xx25/partoss/releases) — Linux
i386, FreeBSD i386, Windows (32-bit), OS/2, DOS (32-bit). На 64-битных Unix
используйте сборку i386.

## Запуск

Формат вызова программы:

```
ParToss <command> [<command>...] [<key>...] [<node>]
```

Основные команды:

| Команда | Режим |
|---|---|
| `In` | импорт писем из пришедших архивов и пакетов |
| `Out` | экспорт писем в почтовые пакеты |
| `Send`, `Squash`, `Pack` | подготовка почтовых пакетов к отправке |
| `Rescan` | повторная отправка почты для определенного адреса |
| `Link` | связывание писем, объединенных общей темой |
| `Post` | автоматическое создание писем по расписанию |
| `Serv` | обработка писем к эхо-менеджеру |
| `Hand` | «ручной» запуск эхо-менеджера |
| `Purge` | удаление старых писем и упаковка базы |
| `Kill` | удаление архивов, не забранных даунлинками в течение определенного времени |
| `Bad` | разбор писем, ранее попавших в область «плохих» писем |

Остальные команды, ключи и коды ошибок — в разделе 7 `doc/partoss.doc`.

## Внешние программы

Для разархивации пришедших почтовых архивов и архивации выходных пакетов
используются внешние программы-архиваторы. Для того, чтобы ParToss смог
правильно определить, какой архиватор вызывать и с какими параметрами, служит
файл описания архиваторов (`compress.cfg`).
